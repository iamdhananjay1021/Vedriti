# VedRiti Tech Stack & Development Guidelines

Strictly follow these technical constraints:

### 1. Mobile App (APK / AAB)
- **Frontend**: React Native + Expo + TypeScript
- **Styling**: NativeWind (Tailwind CSS)
- **Build**: EAS Build (`eas.json` configured for APK direct install & AAB Play Store)

### 2. Backend
- **Framework**: Node.js + Express
- **Database**: MongoDB (Mongoose)
- **Payments**: Razorpay

### 3. Admin Dashboard (Web)
- **Frontend**: Next.js + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Animations**: Motion for React
